## What AegisTools Does

AegisTools streamlines recurring inventory work on Minecraft servers powered by Paper and Java. When a player targets a block, the plugin can choose an appropriate tool, restore usable items from the player's inventory, and arrange tools across the hotbar.

Block exclusions are managed through an in-game interface. Server users can open the blacklist GUI and identify blocks that should not participate in automatic tool selection. The plugin's current functionality is focused on block-breaking assistance and inventory-management helpers.
